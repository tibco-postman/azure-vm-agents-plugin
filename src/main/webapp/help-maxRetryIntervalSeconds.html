Maximum retry interval in seconds for provisioning attempts after failures.

Default: 600 seconds (10 minutes)

When VM provisioning fails, the plugin uses exponential backoff before retrying. The retry interval starts at 10 seconds and doubles with each failure, up to this maximum.

Example:
- 1st failure: wait 10 seconds before retry
- 2nd failure: wait 20 seconds before retry
- 3rd failure: wait 40 seconds before retry
- 4th failure: wait 80 seconds before retry
- 5th failure: wait 160 seconds before retry
- 6th+ failures: wait up to this maximum (default 600s) before retry

This is different from Deployment Timeout, which controls how long to wait for a single VM deployment to complete.

Note: This setting is unrelated to Azure's deployment timeouts. Azure support confirms there is no Azure-defined 10-minute timeout for VM provisioning.
